# BiliMarks · B站学习打点

B站看录播时按一下鼠标中键记住这一刻；课后点一下链接就跳回去看重点。

A Tampermonkey userscript for taking timestamped notes while watching Bilibili lecture videos.
Press the middle mouse button to mark a moment (no pause, no popup). Each mark becomes a clickable link
that jumps back to that second. Marks are saved as daily Markdown files, one per lesson.

---

## 它解决什么问题

**目标用户：备考 / 自学、用 B 站看录播课的人。**

一节课 1–2 小时，老师强调的重点散落在各处。课后想复习，只有两个选择：
重看一遍，或者在进度条上拖来拖去找那几十秒。

**这个脚本把"课上记录"的成本压到接近零：**

```
上课时：听到重点 → 按一下中键 → 继续听（不暂停、不弹窗、不分心）
课后  ：打开当天的 Markdown → 点一下链接 → 直接落到那一刻 → 做笔记
```

**为什么我需要它（个人情况）：**
我有 **ADHD**，专注很难维持。任何"停下来、切窗口、找输入框"的动作都会把我从课上拉走，
所以以前的笔记方案全部失败在"启动成本"上——不是不想记，是记的动作本身太贵。
这个工具的设计原则就一条：**打点必须比记在纸上更省事**。

- 打点后图标变绿显示 `✓ 已记录 00:33`，**看得见确认，但不用看**
- 数据先存本机，同时自动按天写进你自己的文件夹
- 我用的方式是「**课上只打点，课后回看做笔记**」，所以文件只存时间点，不塞正文

## 安装

1. 先装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge 扩展商店里有）
2. 点这个链接 → Tampermonkey 自动弹出安装页 → 点「安装」：

   **<https://raw.githubusercontent.com/zhuoning560Johnny/BiliMarks/main/BiliMarks.user.js>**

3. 打开任意 B 站视频页（`https://www.bilibili.com/video/BV...`）
4. **看到左侧中部出现一个小胶囊「● 0」就算装好了**

第一次按 `Ctrl + 单击图标` 会弹出"选择文件夹"窗口，选一个目录（例如 `D:\打点`）。**只需选一次。**

## 使用

| 动作 | 主要方式 | 备用 | 兜底 |
|---|---|---|---|
| **打点** | **画面空白处按鼠标中键** | `Ctrl+Shift+X` | 单击小图标 |
| **撤销** | `Shift + 中键` | `Ctrl+Shift+Z` | `Shift + 单击小图标` |
| **导出** | `Ctrl + 单击小图标` | `Ctrl+Shift+E` | — |
| **复习** | 悬停图标 → 点时间条目 → 跳转 | | |

- **悬停图标** → 列出本课全部时间点 → 点一条直接跳转（不刷新页面）
- **拖动图标** → 换位置（会记住）
- **右键图标** → 重新选择保存文件夹

**中键只在视频画面内生效**：在进度条、弹幕开关、音量、链接上按中键，仍是网页原本的行为（开新标签、调音量等）。

## 导出的文件长什么样

```
D:\打点\
└─ 2026-11-23\
   └─ 数据结构第3讲_P2_BV1at4y1i7cy.md
```

```markdown
# 数据结构第3讲（P2）

日期：2026-11-23
视频：https://www.bilibili.com/video/BV1at4y1i7cy/?p=2
重点集中在 10:12–25:40

- 10:12  https://www.bilibili.com/video/BV1at4y1i7cy/?p=2&t=612
- 11:05  https://www.bilibili.com/video/BV1at4y1i7cy/?p=2&t=665
```

- 链接是**裸 URL**，在 Obsidian、VS Code、微信、Word 里都能直接点
- 导出时 **2 秒内的相邻点合并成一行**；另给一行「重点集中在 起点–终点」（8 分钟窗口内点数最多的一段）
- **你自己在文件里写的文字不会被覆盖**，脚本只更新它自己生成的那几行

## 和别的方案比

| 方案 | 我的体验 |
|---|---|
| **B 站官方视频笔记** | 要打开侧边面板、在里面操作，步骤多；我只想"按一下就继续听"，它做不到 |
| **[B-Note（哔记）](https://github.com/Xiang-yuZHAO/B-Note)** | 功能很全（时间戳、截图、编辑器、导出），但我这边它依赖的国外 CDN 加载失败，出现过"用完保存后视频打不开"的问题 |
| **纸笔 / 手写** | 打印 PPT → 剪 → 贴 → 手写，两节课花 2.5 小时只产出 4 页纸，且没有结构 |
| **本脚本** | 只做一件事：打点。不接管播放器、不弹面板、零外部依赖 |

**本项目的「时间戳打点」思路参考了 B-Note（MIT 许可）**，代码为独立实现；
文件写入、按天归档、悬停跳转列表是另外设计的。

## 兼容性与已知限制

| 项 | 说明 |
|---|---|
| **浏览器** | 需要 [File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_API)（`showDirectoryPicker`）→ **Chrome / Edge 等 Chromium 内核**。Firefox、Safari 不支持，会降级为"下载 .md 到下载目录" |
| **平台** | B 站**网页版**（不是 PC 客户端；客户端里油猴脚本不运行） |
| **每次重开浏览器** | 第一次导出要按一次 `Ctrl + 单击小图标`（浏览器权限模型，脚本无法静默申请）。图标显示橙色「未存」就是提醒 |
| **原生 `<video>` 全屏** | 全屏由浏览器绘制，脚本插不进元素；此时打点仍有效，但只有提示音反馈。**建议用 B 站的容器全屏**，图标和列表都在 |
| **B 站改版** | 依赖播放器 DOM 结构。改版后可能出现「未识别主视频」，此时图标点击和键盘仍可用 |
| **数据存储** | 原始点只存浏览器 `localStorage`（键前缀 `bn4_`）。清除站点数据会丢，但已导出的 `.md` 不受影响 |
| **分 P 视频** | 每个分 P 独立记录、独立文件（`标题_P2_BV….md`），跳转链接自带 `?p=N` |

<details>
<summary>实现要点（给想看代码的人）</summary>

- 单文件、零外部依赖、`@grant none`（因为文件系统能力在油猴沙盒里无法调用）
- **中键判定**：只在播放器容器矩形内接管；`mousedown` 即 `preventDefault()`（阻止 Windows 自动滚动）；
  按住后位移 ≥5px 或时长 ≥600ms 视为取消；按住期间滚轮事件被拦截并取消本次打点；
  链接、按钮、输入框、进度条、弹幕开关等一律放行
- **写入时合并**：原始点不删不改，导出时按视频时间升序、2 秒窗口合并；「重点集中段」用滑动窗口找点数最多的 8 分钟
- **手写保护**：写文件前读旧内容，只替换脚本自己生成的行与区块，其它文字原样保留
- **数据异常可见**：`localStorage` 读失败或格式损坏时，图标显示 `● ?` 与「数据异常」，并中止写入，不覆盖原数据
- **避免双触发**：键盘事件用 `WeakSet` 认领；iframe 只转发带序号的动作用消息；中键手势一次性消费

</details>
